<threat_model>
- T-38-09 自动重试：前端把网络、stale 或 Provider unknown 解释为可静默重试，从而重复 Provider/authority effects。
- T-38-10 错误泄露：错误视图暴露 confirmation、HMAC、secret、原始证据、路径、Provider body 或完整 request payload。
- T-38-11 重放误解：用户把 `replayed=true` 看成第二次写入，或同 key 异 payload 被客户端用新 key 掩盖。
- T-38-12 跨 origin 写入：非同源 POST/OPTIONS 触发 guarded route 或影响 orchestration/Analysis/Pilot/Calibration authority。
- 阻断条件：所有负路径应保持零自动 Provider 调用、零自动外部动作、零自动 promotion；测试必须使用 disposable fixture，不得写入用户真实 authority。
</threat_model>
