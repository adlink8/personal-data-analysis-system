<runtime_artifact_contract>
Do not use `latest`, stdout scraping, or a hand-written run ID. Every command resolves identity from a persisted JSON artifact:

```powershell
$pilotManifest = Resolve-Path 'integration/analysis/ai_context/knowledge_unit_pilot_manifest.json'
$preflightPath = 'integration/analysis/ai_context/knowledge_unit_pilot_preflight.json'
python integration/scripts/build_knowledge_units.py --preflight --inventory $pilotManifest --model gpt-5.6-luna --report $preflightPath
$preflight = Get-Content -LiteralPath $preflightPath -Raw | ConvertFrom-Json
if ($preflight.status -ne 'ready' -or [string]::IsNullOrWhiteSpace([string]$preflight.actual_model_id)) { throw 'Pilot model preflight is not ready' }

$pilotReportPath = 'integration/analysis/ai_context/knowledge_unit_pilot_report.json'
python integration/scripts/build_knowledge_units.py --start --inventory $pilotManifest --model $preflight.actual_model_id --report $pilotReportPath
$pilot = Get-Content -LiteralPath $pilotReportPath -Raw | ConvertFrom-Json
$runId = [string]$pilot.run_id
if ([string]::IsNullOrWhiteSpace($runId)) { throw 'pilot report missing run_id' }
python integration/scripts/evaluate_knowledge_unit_extraction.py --run-id $runId --report $pilotReportPath --strict
$pilot = Get-Content -LiteralPath $pilotReportPath -Raw | ConvertFrom-Json
if ($pilot.gate.status -ne 'PASS' -or $pilot.inventory_hash -ne $preflight.inventory_hash -or $pilot.actual_model_id -ne $preflight.actual_model_id) { throw 'Pilot gate or lineage verification failed' }
```

`knowledge_unit_pilot_preflight.json` is the sole source of `actual_model_id`; `knowledge_unit_pilot_report.json` is the sole source of `run_id`. Required report fields are `run_id`, `status`, `inventory_hash`, `sample_count`, `actual_model_id`, `prompt_hash`, `schema_hash`, `config_hash`, `dataset_hash`, `paid_call_count`, `gate.status`, and `gate.checks`. Resume uses the exact persisted ID: `python integration/scripts/build_knowledge_units.py --resume $runId --report $pilotReportPath`.
</runtime_artifact_contract>
