# Plan 17-04: Promotion Gate Integration and Rollback UAT

## Objective

把全面评测从“报告”变成强制发布纪律：candidate → eval → gate → canary → promote，失败时 active 100% 不变。

**Decisions enforced:** D-01（五路完整）、D-02（同场协议）、D-03（分层归因）、D-04（本地隐私）、D-05（candidate-before-promote）、D-06（judge 校准后才入 gate）。
