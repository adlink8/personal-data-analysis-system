# Plan 17-02: Unified Five-Mode Retrieval Benchmark

## Objective

同一命令、同一 dataset/scorer 对 Raw、L1、L2-only、L1+L2、Hybrid 五路运行 paired A/B，量化绝对提升、相对提升和置信区间。

**Decisions enforced:** D-01（五路固定模式）、D-02（同场协议）、D-03（Hybrid 分层归因）、D-05（active 只读 baseline）。

## Exit gate

五路必须共享 dataset hash/scorer/top-k；secret/privacy hit=0；任何模式缺失不得宣称全面提升。
