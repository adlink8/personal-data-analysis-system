<objective>
Create the additive schema and snapshot-bound immutable run contract that all Phase 25 state and change analysis uses, without creating a second knowledge authority or mutating Phase 24 lifecycle state.
</objective>

<threat_model>
- Authority confusion: analysis rows are registered only as `a.personal_change`; they never become canonical KU, snapshot members, lifecycle actions or serving pointers.
- Cross-snapshot or stale evidence: require the resolved snapshot ID/hash and member version for every evidence ref and reject mixed or unresolved provenance.
- Private payload persistence: store typed refs, hashes and minimum metadata only; secret, blocked or ineligible evidence vetoes the whole assertion/run.
- Partial or duplicate publication: canonical checksums, one transaction, immutable-row triggers and unique run identity make retry idempotent and fault injection atomic.
- Severity: any authority, privacy, lineage or atomicity failure blocks completion.
</threat_model>
