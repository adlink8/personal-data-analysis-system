<objective>
Expose one privacy-safe read interface for personal state/change intelligence and validate it with deterministic fixtures plus a non-mutating live dry-run that truthfully preserves Phase 24 release gates.
</objective>

<threat_model>
- Interface drift: all transports call the same typed backend and contract fixtures compare normalized responses.
- Privacy leakage: metadata-only defaults, response allowlists and secret/ineligible fault fixtures fail closed across every transport.
- Accidental live mutation or cost: acceptance permits only read-only/dry-run commands and verifies database/snapshot/watermark fingerprints before and after; network/paid paths are absent.
- False closure of Phase 24: checkpoint files and strict statuses are read, reported and left unchanged; no agent supplies reviewer identity, approvals, labels or lifecycle decisions.
- Severity: any mutation, privacy leak, cross-snapshot response or fabricated gate evidence blocks completion.
</threat_model>
