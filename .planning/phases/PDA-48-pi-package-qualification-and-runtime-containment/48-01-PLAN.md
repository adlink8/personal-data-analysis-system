# Phase 48-01 Plan — Exact package baseline and supply-chain gate

<objective>
建立独立、可重复安装、机器可判定的 Pi 0.83.0 package candidate，并使版本、integrity、engine、license、repository、install scripts 和 npm audit 中任何未知/高风险项默认阻断。
</objective>

<threat_model>

**Assets:** repository execution environment, npm credentials/proxy settings, product dependency tree, future Pi Kernel process.

**Trust boundaries:** npmjs.org metadata/tarballs → lockfile; lockfile → local node_modules; qualification report → Phase 49 planning gate.

**Threats:**

- **T48-01:** dependency confusion, range drift, tampered tarball, lifecycle script execution or advisory suppression produces a falsely accepted baseline.
- A malicious package places personal paths or environment values in diagnostics.
- An override removes an advisory but breaks Pi runtime compatibility.

**Controls:** exact versions and overrides, lockfile integrity, npmjs.org audit, `npm ci --ignore-scripts`, output key allowlist, later runtime smoke/containment dependency.

**Residual risk:** npm audit coverage and registry metadata are not proof of absence; runtime compatibility and capabilities remain blocked until Plans 02–03 pass.

</threat_model>
