# Phase 48-02 Plan — Runtime resource and capability containment

<objective>
将 Spike 001 的最小 containment 提升为产品候选契约：在真实 Pi package 基线上证明零 ambient resource、零 coding built-in、零凭据发现、零非 allowlisted filesystem/process/network 能力和零 authority 变更。
</objective>

<threat_model>

**Assets:** personal files, auth/settings, local process execution, network egress, canonical/knowledge authorities and governance pointers.

**Trust boundaries:** host filesystem/environment → Pi ResourceLoader; Pi session → custom Domain Tools; probe output → package acceptance.

**Threats:**

- **T48-02:** crafted `.pi`, `.agents/skills`, prompt, context or global agentDir content is loaded despite product policy.
- **T48-03:** built-in Tool, extension or package reaches filesystem, child_process, network or credential material.
- SDK update changes default behavior while existing tests continue to assert only happy-path output.

**Controls:** all `no*` loader flags, in-memory settings/session, `noTools: "builtin"`, exact custom tool registry, isolated HOME/cwd/agentDir, forbidden capability decoys and independent Python fingerprints.

**Residual risk:** Phase 48 does not exercise real Provider traffic or durable Session storage; those remain blocked to later phases.

</threat_model>
