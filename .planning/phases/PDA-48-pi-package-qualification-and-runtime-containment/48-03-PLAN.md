# Phase 48-03 Plan — Composite package decision and Phase 49 release gate

<objective>
把 supply-chain、override compatibility、runtime containment、privacy 和 zero-mutation 证据合成为唯一 package decision，使 Phase 49 只能消费同一 exact-lock run 的 `accepted` 结果。
</objective>

<threat_model>

**Assets:** package acceptance decision, audit evidence, Phase 49 dependency gate and historical reproducibility.

**Trust boundaries:** Plan 01/02 test outputs → composite report; report → governance decision; decision → roadmap transition.

**Threats:**

- **T48-04:** stale, partial or mixed-lock evidence is combined into a false pass.
- Report path/body leaks personal data or credentials.
- Manual text says accepted while machine decision is conditional/rejected.
- Qualification script mutates product dependencies, authority state or active runtime.

**Controls:** exact input checksums, same-run ID, required evidence set, deterministic severity/status lattice, independent governance tests and accepted-only transition rule.

**Residual risk:** upstream release after the decision can invalidate the baseline; requalification triggers remain mandatory before upgrade.

</threat_model>
