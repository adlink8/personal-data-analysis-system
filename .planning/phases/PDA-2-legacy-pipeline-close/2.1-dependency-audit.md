1. **新管道（pk-sync conversations）不引用任何在册模块**。sync.py 只引用

   build_google_normalized_events、knowledge/doctor_ku。

   run_pipeline.py 的 `--legacy-integrated` 字符串分发、legacy 消费方）或
   **历史遗留 evaluation/forensics 引用**，无活跃 import 者。
3. **例外（真实活跃 import）**：tests/ 下 2 个测试 import 在册模块（test_import_pipeline、
   test_conversation_summary_parse），需按"标记 skip"策略处理（见 2.2）。
4. **enrich_unified_events.py**：未被新管道使用；其输出表 unified_events_rich 仅被
   legacy 集成链消费（build_deep_profiles、build_context_doc、build_merge_layer、
   build_context_memory、extract_memory_candidates_from_bundles、
   build_memory_evidence_bundles），全部 table_exists 门控、可容忍缺失。
   dashboard.py 仅 help 文本引用（无 import）。
