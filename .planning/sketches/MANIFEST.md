# Sketch Manifest

## Design Direction

安静、克制的桌面工作壳：启动后立刻进入一段可继续的对话，而不是传统仪表盘。颜色取自当前 Codex Desktop 实机采样：主内容 #181818、侧栏/标题区域 #1A2228、浮层 #242424、选中与边界层 #2D3237；文字采用白/浅灰，绿色只表达成功或在线。AI 的能力被清楚表达为受限、可审计的只读查询与建议，而非拥有数据或行动权。

## Reference Points

当前 Windows Codex Desktop（实机采样的深色层级与 Segoe UI 字体）、Zed / ZCode 一类的代码工作台：紧凑分栏、可切换上下文、低干扰工具面板。
