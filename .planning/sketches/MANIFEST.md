# Sketch Manifest

## Design Direction

安静、克制的桌面工作壳：启动后立刻进入一段可继续的对话，而不是传统仪表盘。界面以深色中性表面、低饱和薄荷绿状态和细边界组织个人工作上下文；AI 的能力被清楚表达为受限、可审计的只读查询与建议，而非拥有数据或行动权。

## Reference Points

Codex、Zed / ZCode 一类的代码工作台：紧凑分栏、可切换上下文、低干扰工具面板。
