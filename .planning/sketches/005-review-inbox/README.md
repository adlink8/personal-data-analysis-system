# Sketch 005: Review Inbox

## Design Question

在固定的 Codex 式双栏壳中，如何让高影响候选逐项可查，低风险候选可批量处理，并把冲突和不确定性留在显眼的位置？

## How to View

在浏览器打开 .planning/sketches/005-review-inbox/index.html。

## Variants

- **A: 来源批次审核** — 用同步、简报、问答等来源批次组织候选。
- **B: 列表 + 详情 + 证据** — 先选择候选，再编辑并按需查看证据。
- **C: 对话式审核** — 对话逐项提出候选，并展示批次进度和跳过。

## What to Look For

比较高风险是否足够醒目、编辑是否保留 AI 原稿、冲突选项是否可理解，以及成功、延后、撤销和空态是否能保持审核脉络。
