# Sketch 004: Daily Brief

## Design Question

在固定的 Codex 式双栏壳中，今天的进展、决定、变化、经验、问题和建议如何成为一段可继续、可查证的对话开场？

## How to View

在浏览器打开 .planning/sketches/004-daily-brief/index.html。

## Variants

- **A: 对话内简报** — 首条助手消息就是可渐进展开的固定栏目简报。
- **B: 置顶简报画布** — 可折叠摘要固定在对话上方，随时回看。
- **C: 自上次简报以来的时间流** — 用时间覆盖段和事件簇解释遗漏天数，并从事件回到对话。

## What to Look For

比较启动时的同步反馈、简报与继续对话的衔接、来源限制是否清楚，以及不同项目与离线状态下信息是否仍然可用。
