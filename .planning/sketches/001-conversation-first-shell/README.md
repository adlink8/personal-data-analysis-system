# Sketch 001: Conversation-first Shell

## Design Question

在不退化成传统数据仪表盘的前提下，怎样把今日简报、项目、收件箱与个人模型能力放在可随时调用的位置？

## How to View

在浏览器打开 `.planning/sketches/001-conversation-first-shell/index.html`。

## Variants

- **A: Codex 式经典双栏** — 永远可见的项目与工作入口，中央保留稳定对话区。
- **B: 对话中心 + 上下文检查器** — 对话占据主舞台，右侧用可切换检查器解释当前依据。
- **C: 可折叠轻量导航 / 专注模式** — 默认最少界面，按需展开导航与上下文抽屉。

## What to Look For

比较首屏是否足够直接、切换项目是否容易，以及在需要查证时上下文是否触手可及但不会打断思考。注意收起导航、打开检查器与专注模式后的工作节奏。
