# Sketch 007: Project & Topic

## Design Question

如何让代码项目、学习或生活目标都拥有可编辑的当前状态，并与跨项目主题、决定、经验和证据历史相连？

## How to View

在浏览器打开 .planning/sketches/007-project-topic/index.html。

## Variants

- **A: 当前状态中心** — 状态摘要和各类项目卡片同屏可见。
- **B: 证据时间线优先** — 以状态变化和决定的时间线为主。
- **C: 项目-主题双视角** — 在项目和跨项目主题之间切换并管理关联。
- **D: 对话原生能力** — 项目与主题不再是一级页面；它们由对话、命令面板和确定事件按需唤起。

## What to Look For

比较项目/主题是否应该成为常驻页面，还是在对话中按需出现；也留意主动提示是否解释了触发原因、是否只在重大冲突时抢占注意力。
