# Sketch 003: Personal Model

## Design Question

在固定的 Codex 式双栏壳中，用户如何理解、校正和限制个人模型的十个维度，同时始终能回到原始证据？

## How to View

在浏览器打开 .planning/sketches/003-personal-model/index.html。

## Variants

- **A: 维度地图 + 详情** — 从十个并列维度进入一个有证据和反例的详情面。
- **B: 证据笔记本** — 沿“证据 → 模式 → 稳定倾向 → 工作原则”阅读模型。
- **C: 时间演变** — 用阶段与转折点对比维度的变化，并按情境回看证据。

## What to Look For

比较哪种方式最容易看出结论的依据、反例与适用情境；也留意用户纠正、冻结或禁止个性化后，系统是否清楚地表达了边界。
